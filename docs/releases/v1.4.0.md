# HeaderProof v1.4.0

This release moves the scanner toward a smaller public CLI and stricter evidence-driven behavior.

- Replaces profile-oriented CLI behavior with one default scan model, stdin/list input, per-host rate limiting, severity filtering, and optional `headerproof.yaml` configuration.
- Uses declarative templates for request, matcher, extractor, and evidence-gate decisions; specialized multi-request proof workflows stay bounded while safe same-target HTTP detector classes can be added without Python detector changes.
- Adds self-hosted DNS/HTTP OOB confirmation for blind header callbacks with end-to-end proof regression coverage.
- Adds real Varnish and nginx cache fixtures, provider-aware Cloudflare/Fastly cache semantics, reproducible precision/recall output, and an explicit DVWA low-CSRF false-negative measurement.
- Adds SARIF export, CI exit-code discipline, single-file binary builds, signed release checksums, PyPI packaging, and a multi-architecture container workflow.

The release does not claim victim impact from a technical signal. Findings still require the detector proof gate to pass, and real-world impact remains a separate validation step.
