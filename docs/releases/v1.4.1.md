# HeaderProof v1.4.1

This patch completes the v1.4 distribution path after the first container publish exposed a missing Linux build dependency.

- Fixes the multi-architecture Docker build by installing `binutils` in the build stage.
- Adds `ca-certificates` to the runtime image for HTTPS scanning.
- Retains the v1.4.0 scanner, provider-validation, binary, checksum, and signing behavior.
