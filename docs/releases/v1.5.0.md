# HeaderProof v1.5.0

This release publishes the Phase 5–7 hardening work completed after v1.4.1 while keeping the evidence schema at v1.2.

- Stabilizes CI consumption with documented stdout/stderr separation and exit codes: clean `0`, finding `1`, scanner error `2`, interrupted `130`.
- Adds hash-locked evidence-schema compatibility through `schemas/manifest.json` and regression tests that bind the runtime schema version to published schema files.
- Documents and validates the independently versioned HeaderProof Action v1 integration against the published scanner contract.
- Adds regression-tested project-proof documentation that clearly separates controlled fixtures from publishable real-world findings.
- Adds a factual discovery/contribution contract, eight bounded `good first issue` tasks, focused GitHub security topics, and tracked external security-list distribution.
- Retains the v1.4 scanner engine, declarative templates, OOB confirmation, SARIF/JSONL output, native release binaries, signed checksums, and multi-architecture container publishing.

The controlled proof-gate test corpus remains explicitly scoped; fixture measurements are not presented as internet-wide accuracy claims.
