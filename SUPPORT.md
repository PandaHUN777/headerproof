# Support

Use the channel that matches the kind of help you need.

- **Bug in HeaderProof:** open a Bug report issue with a minimal, sanitized reproduction.
- **Usage question:** use GitHub Discussions → Q&A.
- **Feature or detector idea:** use GitHub Discussions → Ideas before opening an implementation issue.
- **Contribution plan:** use GitHub Discussions → General when the work is not already scoped in an issue.
- **Security vulnerability in HeaderProof itself:** use GitHub's private vulnerability reporting. Do not open a public issue.
- **Third-party target finding:** do not post target details here. Follow that target's authorized disclosure process.

Issues are for reproducible defects and accepted, scoped work. Discussions are for questions, proposals, design exploration, and community feedback.
